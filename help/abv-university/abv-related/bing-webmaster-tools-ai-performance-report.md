# Rapport sur les performances de l’IA pour les outils de webmaster Bing

Découvrez comment le nouveau Rapport sur les performances de l’IA de Microsoft dans les outils de webmestre Bing permet de suivre la fréquence à laquelle votre contenu est cité comme source dans les réponses générées par l’IA et ce qu’il signifie pour l’optimisation du moteur de génération (GEO).

## À qui s&#39;adresse cette vidéo ?

* Administrateurs, dirigeants et utilisateurs qui effectuent le suivi de la visibilité du contenu dans les expériences de recherche et d’IA
* Les spécialistes marketing et les équipes de contenu se sont concentrés sur la découverte géographique et pilotée par l’IA

## Contenu vidéo

Dans cette vidéo, vous apprendrez :

* Comment le rapport de performances de l’IA ajoute une couche d’analyse de visibilité de l’IA aux outils de webmaster Bing existants
* Mesures principales dont il fait état, notamment le nombre total de citations, le nombre moyen de pages citées et les données de citation au niveau de la page
* Comment le rapport révèle les requêtes de répartition derrière les citations et pourquoi il n’expose pas les invites sous-jacentes
* La différence entre les données de citation et le rapport de performances de recherche classique sur les clics, les impressions et le classement
* Pourquoi cela est important pour votre stratégie GEO et comment cela complète Adobe Brand Visibility
