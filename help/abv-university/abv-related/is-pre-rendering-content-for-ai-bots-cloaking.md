# Le pré-rendu du contenu pour les robots d’IA est-il masqué ?

Non. Le pré-rendu permet simplement aux agents d’IA de voir le même contenu qu’un être humain, et il suit les mêmes conseils que Google donne pour les JavaScript côté client lourds.

## À qui s&#39;adresse cette vidéo ?

* Administrateurs et utilisateurs préoccupés par l’optimisation et le cloquage de l’IA
* Équipes dont les pages reposent sur un JavaScript côté client

## Contenu vidéo

Dans cette vidéo, vous apprendrez :

* Fonction du pré-rendu : diffusez une version statique d’HTML afin que les agents d’IA puissent voir la page.
* Pourquoi cela reflète les propres conseils de Google sur le rendu JavaScript
* Comment la définition Google du cloaking dépend de l&#39;intention de manipuler
* Pourquoi faciliter la lecture d’un contenu n’est pas de la manipulation
* Pourquoi l’exécution dans le réseau CDN en fait un processus naturel à faible risque
