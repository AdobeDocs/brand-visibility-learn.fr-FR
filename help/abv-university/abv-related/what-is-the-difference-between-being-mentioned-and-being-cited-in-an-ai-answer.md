# Quelle est la différence entre être mentionné et être cité dans une réponse d’IA ?

Une mention nomme votre marque dans le texte ; une citation lie votre page en tant que source. Cette vidéo explique la différence et pourquoi les citations sont le signal de visibilité le plus fort.

## À qui s&#39;adresse cette vidéo ?

* Marketeurs et utilisateurs interprétant la manière dont l’IA représente leur marque
* Équipes distinguant les mentions de marque des citations réelles

## Contenu vidéo

Dans cette vidéo, vous apprendrez :

* Qu’est-ce qu’une mention : votre marque nommée dans le texte de réponse
* Qu’est-ce qu’une citation : un lien vers votre page comme source complémentaire
* Pourquoi une mention peut provenir de données d’entraînement sans récupération
* Comment la récupération (RAG) est ce qui produit une véritable citation
* Pourquoi une citation est un signal plus fort que votre marque a été utilisée comme preuve
